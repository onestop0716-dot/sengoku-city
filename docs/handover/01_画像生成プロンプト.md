# 引継ぎプロンプト①: 画像生成用（ビジュアルの方向性を決める）

画像生成AIに渡す指示です。共通の前提を最初に貼り、続けて作りたい画面のプロンプトを1つずつ渡します。
英語のプロンプトは、英語の方が通りやすい画像生成AI向けです。

---

## 共通の前提（最初に貼る）

```
あなたはゲームのアートディレクターです。次のブラウザゲームのビジュアル案（コンセプトアート）を作ってください。

■ ゲームの概要
- タイトル（仮）:「戦国七雄・都市開発シミュレーション」
- 舞台: 古代中国・戦国時代の末期。前247年（秦王政が即位した年）から始まる。
- 遊び方: プレイヤーは七つの大国（秦・趙・魏・韓・楚・斉・燕）のどれかに仕える「県令」となり、一つの都市を発展させる。道路を引き、住居・農地・市・工房・軍営の区画を置くと、民が自分で家を建てて街が育つ。出世すると郡守、さらに相邦または大将軍になり、天下統一を目指す。
- 画面: 斜め上から見下ろす3Dの街（回転・ズーム可）。都市開発が常に主役。
- 遊ぶ端末: PC のブラウザと iPad（Safari）。横長 16:9 が基本。

■ 目指す雰囲気
- 明るく温かいアニメ調。輪郭線がはっきりしたセル塗り。手描きの絵本や地図のような親しみやすさ。
- 色: 黄土色の大地、青い川、緑の畑、灰色の瓦屋根、朱色の柱、金色のアクセント。空は青く、白い雲。
- UI は木の枠と羊皮紙（巻物）の質感、金の縁取り、太めのアイコン。文字は日本語。

■ 時代考証（必ず守る）
- 建物は木造・版築（土を突き固めた壁）・瓦葺きまたは茅葺き。城壁は版築の土壁。
- 服装は戦国時代の漢服（交領の深衣など）。乗り物は牛車・馬車・戦車（二輪の馬車）・舟。
- 描いてはいけないもの: 紙、鐙（あぶみ）、椅子やテーブルに座る暮らし、仏教・寺院・仏塔、綿、茶、トウモロコシや唐辛子など新大陸の作物、火薬・大砲、明清風の楼閣や反り返りの強い屋根、一輪車（手押し車）、アーチ型の石橋、磁器。
- 漫画・アニメ・映画『キングダム』のキャラクター、デザイン、構図、台詞、ロゴは一切使わない。実在の俳優や有名作品のキャラクターにも似せない。

■ 案内役キャラクター
- 茶色いフクロウの「ホウ」（県令を見守る物知りなフクロウ）。丸い体、大きな目、親しみやすいデフォルメ。画面右下で吹き出しで助言する。
- 他のキャラクターは出さないか、名前のない民衆として小さく描く。

■ 出力
- 1枚ごとに「どの画面か」が分かる構図にする。
- 文字が崩れる場合は、文字を入れずに枠だけ描く（文字は後でゲーム側で入れる）。
```

## A. タイトル画面

```
タイトル画面のキービジュアルを作ってください。
- 中央上にゲームのロゴ「戦国七雄」と副題「都市開発シミュレーション」。書道風の力強い文字、朱色と金。（文字が崩れるならロゴの場所だけ空ける）
- 背景: 夕焼けに染まる黄河流域。手前に版築の城壁と城門、城内に瓦屋根の街並み、遠くに山々と雲。旗がはためく。
- 下部に羊皮紙のボタン「はじめから」「続きから」が並ぶ余白。
- 16:9、アニメ調のセル塗り、温かい色。
```

English:
```
Title screen key visual for a city-building game set in ancient China, Warring States period (247 BC). Anime cel-shaded style with bold outlines, warm sunset light. A rammed-earth city wall and wooden gate tower in the foreground, a city of grey tiled roofs and vermilion pillars inside, the Yellow River winding to distant mountains and clouds, banners in the wind. Leave space at the top center for a calligraphic logo and at the bottom for two parchment-style buttons. 16:9. No paper, no stirrups, no Buddhist temples or pagodas, no Ming/Qing style pavilions, no arched stone bridges, no gunpowder. Do not resemble the manga "Kingdom" or any existing characters.
```

## B. メインのゲーム画面（都市）

```
プレイ中のメイン画面のモックアップを作ってください。
- 斜め上45度から見下ろした城郭都市。四角い版築の城壁と城門、中央に官府（県の役所）、碁盤目の道路、市場、住居の家並み、外側に粟や麦の畑、川と船着場、牛車と人々。
- UI: 上=資源バー（銭・穀物・人口・民忠・治安、日付、速度ボタン）／左上=やるべきことの札が3枚／右上=ミニマップ／右=選んだ建物の情報／下=建築バー（タブ: 住居・農地・商業・工房・軍事・建築、アイコン付きのボタン）／右下=フクロウの案内役と吹き出し。
- 主要な建物の上に小さな名札。
- 16:9、アニメ調、明るい昼。
```

English:
```
In-game screen mockup of an isometric-like 3D city-building game, ancient China Warring States period. 45-degree top-down view of a walled city: square rammed-earth walls and gate towers, a government hall in the center, grid roads, a marketplace, rows of timber houses with grey tile or thatched roofs, millet and wheat fields outside, a river with a small dock, ox carts and townspeople. Game UI framed in carved wood and parchment with gold trim: top resource bar with icons, three quest cards top-left, minimap top-right, info panel on the right, bottom build bar with category tabs and icon buttons, a cute brown owl advisor with a speech bubble bottom-right. Small name labels above key buildings. Anime cel-shaded, bold outlines, bright daylight, 16:9. Historically plausible only: no paper, stirrups, Buddhist temples, wheelbarrows, arched stone bridges, porcelain, gunpowder, New World crops.
```

## C. 全国マップ画面

```
全国マップ画面を作ってください。
- 古地図風の羊皮紙に描いた戦国七雄の勢力図。七国を色分け（秦=深紅、趙、魏、韓、楚、斉、燕）。黄河・長江、山脈、主要都市の印。
- 都市の間を進む商隊の小さな絵、国境の旗。
- 周りに木枠、右側に「概況・貿易・外交・王命・郡」のタブが並ぶ余白。
```

## D. UI 部品のセット

```
ゲームの UI 部品を1枚にまとめたシートを作ってください。透過しやすい無地の背景。
- 木枠のパネル（大・小）、羊皮紙のパネル、金の縁のボタン（通常・押下・無効）、タブ、吹き出し、ツールチップ。
- アイコン（太い線、単色＋差し色）: 銭、穀物、人口、民忠（ハート）、治安（盾）、住居、農地、市、工房、軍、道路、撤去、井戸、穀倉、城壁、城門、宗廟、船着場、設定、メニュー、一時停止、再生。
- アニメ調で統一。
```

## E. 案内役フクロウ「ホウ」の表情差分（任意）

```
案内役の茶色いフクロウ「ホウ」を4つの状態で描いてください。同じ絵柄・同じ大きさ・透過背景。
1. 通常（にこやか） 2. 喜び（羽を広げて跳ねる、音符） 3. 困り（首をかしげて汗） 4. 警告（羽を上げて驚き、赤い「！」）
丸い体、大きな目、短い耳羽、デフォルメ。既存作品のキャラクターに似せない。
```

## 決まったビジュアルを開発に渡すとき
- 採用した画像を「内容制作用」のセッションに添付し、「この画像を目標の見た目とする」と伝える。
- 画像生成AIの利用規約で、生成画像をゲームに使えるか（商用・公開の可否）を確認する。素材としてゲームに組み込む場合は `CREDITS.md` に記録する。
