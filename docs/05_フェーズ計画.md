## フェーズ1の詳細（次に着手するもの）

1. `package.json`、`index.html`、`tools/serve.mjs`、`vendor/three/` 同梱（CREDITS.md に記録）
2. `core/rng.js` `core/grid.js`、`sim/terrain/`（ハイトマップ + 川 + 森 + 資源、都市テンプレート反映）、テスト（同一シードで同一地形）
3. `render/terrain-mesh.js`、`render/camera.js`（360度回転・ズーム・パン）
4. `sim/roads.js`（線引き、接続判定）、`sim/zones.js`（矩形設定、繁栄度、レベル、新築・衰退）、テスト
5. `render/models/`（庶民住居 3レベル × 3種、農家、道路、木）、`render/buildings.js`（InstancedMesh）、`data/assets.json`
6. `ui/toolbar.js` `ui/hud.js`（ツール切替、簡易HUD）、`app/game-loop.js`（速度・一時停止）
7. `.github/workflows/sengoku-city-pages.yml`
8. `data/`: nations / cities / terrain / zones / buildings / assets / balance / terms の初版

## テストの範囲（各フェーズで追加）
- P1: 乱数の再現性、地形生成、道路接続、繁栄度とレベル変化
- P2: 暦、税計算、人口増減、需要メーター
- P3: 効果範囲、城壁の閉包判定、経路探索
- P4: 登用・任命効果、研究の進行と解禁
- P5: 価格変動、商隊の往復、外交の友好度、昇進判定
- P6: 戦闘判定（決定性、城壁の効果）
- P7: イベント発火、セーブの往復、データ検証
