# 04 フォルダ構成

```
├── data/                     # ゲーム内容の JSON（03_データ定義設計.md 参照）

│   ├── crops.json  structures.json  goods.json  persons.json  offices.json

│   │   ├── economy.js        # 税・収支・価格
│   │   ├── population.js     # 人口・身分・民忠・治安・衛生
│   │   ├── demand.js         # 需要メーター
│   │   ├── agents.js         # 表示用住民・乗り物の「論理」位置（描画とは別）
│   │   ├── persons.js        # 人材・官職・登用

│   │   ├── trade.js          # 交易品・商隊

│   │   ├── events.js         # ランダム／史実イベント
│   │   ├── achievements.js

│   │   ├── scene.js  camera.js  lights.js

```

## 依存関係の向き（守ること）
```
core ← sim ← app → render
        ↑          ↑
       data       ui → sim(commands のみ)
```
- `sim` は `core` と `data` だけに依存する。
- `render` と `ui` は `sim` の状態を読むが、書き換えは `commands` 経由。
- `app` が全体を組み立てる。

## GitHub Pages

- ビルドなしなので、ローカルで動くものがそのまま公開される。
