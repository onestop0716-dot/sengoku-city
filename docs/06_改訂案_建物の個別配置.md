## 1. 何が変わるか（要約）

- 区画を塗る → 民が自動で建てる、をやめる。**プレイヤーが建物を1つずつ選んで置く**。
- 置いた後の「育つ・廃れる」は自動のまま（満足度による自動格上げ・衰退）。
- 人口・仕事・税・収穫の計算は「置いた建物」をもとにする（いまも建物一覧で計算しているため、大部分はそのまま使える）。
- 需要メーター（住・農・商・工）は廃止し、「空き家」「働き口」「失業」「入居待ち」の数で示す。

## 2. データの形

### 2.1 置ける物はすべて同じ共通項目を持つ
`buildings.json`（人が住む・働く・育つ建物）と `structures.json`（公共・インフラ）は分けたまま、次の共通項目をそろえる。`zones.json` は削除する。

```jsonc
{
  "id": "house_commoner",
  "name": "庶民の家",
  "tab": "residential",            // 建築バーのタブ: residential / farm / commerce / industry / military / public
  "size": [1, 1],                  // 何マス×何マス（回転すると入れ替わる）
  "place": "single",               // single=1つずつ / line=線で引く / area=範囲で埋める（畑は single と area の両方）
  "cost": { "qian": 20, "wood": 4, "stone": 0 },
  "buildDays": 10,
  "upkeep": 0,                     // 月の維持費（銭）
  "requires": {
    "roadAdjacent": true,          // 入口が道路に接する（住居・市・工房）
    "roadWithin": 0,               // 道路から何マス以内（畑・伐木場などは 3〜6）
    "terrain": ["plain", "hill"],  // 置ける地形
    "water": false,                // 水が届く所だけ
    "resourceNear": null,          // { "id": "iron", "radius": 6 } など
    "unlock": { "tech": null, "rank": null }
  },
  "levels": [
    { "level": 1, "capacity": 5, "models": ["house_c1_a", "house_c1_b", "house_c1_c"] },
    { "level": 2, "capacity": 8, "upgrade": { "satisfaction": 65, "needs": ["water", "market"] } },
    { "level": 3, "capacity": 12, "upgrade": { "satisfaction": 75, "needs": ["water", "market", "temple"] } }
  ]
}
```

- 工房は `jobs` と `produces`、畑は `crop`、公共建築は今の `effects`・`radius` をそのまま持つ。
- 文言（置けない理由など）はすべて `data/terms.json` か新しい `data/messages.json` に置く。

### 2.2 建築バーのタブ（画像の配置に合わせる）
常に表示: 選択 / 道路 / 撤去 / 移動 / 回転。タブは次の6つ。

| タブ | 中身 |
|---|---|
| 住居 | 庶民の家 1×1、士の邸 2×2、卿大夫の邸 3×3 |
| 農業 | 畑 4×4（粟・黍・麦・菽・稲・桑・麻）、農家 1×1、灌漑水路（線）、堤防（線）、穀倉、社稷壇 |
| 商業 | 市の店 1×1、市亭、関所、伝舎、船着場 |
| 工業 | 工房 2×2（製鉄・青銅器・陶器・製塩・織物・漆器・車両・武器）、**伐木場**、**石切場** |
| 軍事 | 兵舎、馬厩、武庫、練兵場、城壁（線）、城門、望楼、烽火台 |
| 公共 | 官府、井戸、橋（線）、宗廟、学宮/客館、宮殿、獄 |

工房の種類は、いまは近くの資源から自動で決まるが、今後は**プレイヤーが選ぶ**。条件（近くに鉄の資源など）を満たさなければ赤枠と理由を出す。

## 3. 操作の流れ

### 3.1 1つずつ置く（single）
1. 建築バーで建物を選ぶ。
2. カーソル（指）の位置に**半透明の見本**と足もとの枠を出す。置ける＝緑、置けない＝赤。
3. 赤のときは理由を出す（複数あれば全部）: 道路から遠い / 水が届かない / 地形が合わない / 他の建物と重なる / 銭・木材・石材が足りない / 未解禁（解禁条件も出す）/ 近くに材料がない。
4. 向き: 既定は「入口が道路に面する向き」（いまの `chooseFacing` を使う）。R キー・回転ボタンで 90 度ずつ回す。
5. PC はクリック、タッチは指を離すと仮置き →「決定」「取消」（設定「操作の確認」はいまのまま）。
6. 決定で費用を払い、建設が始まる（建設日数ののちに完成）。

### 3.2 並べ置き・範囲で埋める
- 並べ置き: 1つずつ置く建物をドラッグすると、ドラッグの向きに隙間なく並べる（畑・家・井戸など）。置けない位置は赤で示し、置ける分だけ置く。
- 範囲で埋める（畑）: 「範囲」に切り替えてドラッグした長方形を 4×4 の畑で埋める。半端な列は使わず、斜線で示す。合計費用と枚数を出してから決定。森は伐採して畑にする（いまと同じ。伐採した分は木材になる）。

### 3.3 線で引く（line）
道路・城壁（版築）・灌漑水路・堤防・橋。ドラッグで L 字の線を引き、**長さ × 単価**の費用を出してから決定。城門は城壁の上に1つずつ置く（城壁が道路を横切る所に自動で置く、はいまのまま）。

### 3.4 移動・撤去・元に戻す
- 移動: 建物を選んで「移動」→ 見本が付いてくるので新しい場所で決定。建設中なら無料。完成済みは費用の 25% がかかり、建設日数の半分だけ工事になる（その間は住めない・働けない）。
- 撤去: 費用は戻らない。木材の半分だけ戻る。
- 元に戻す（最大5件）: 置く・移動・線引きを戻せる（費用は全額戻す）。撤去は戻せない（いまのまま）。

## 4. 人口・経済の計算をどう置き換えるか

| いま（区画方式） | これから |
|---|---|
| 区画の空きマスに民が自動で新築 | なし。新築はプレイヤーだけ |
| 繁栄度でレベル上下 | 建物ごとの**満足度**（いまの繁栄度の式から「需要」「区画」を除いたもの）でレベル上下。レベルの条件（`levels[].upgrade.needs`: 水・市・宗廟など）も満たす必要あり |
| 格上げの費用は県の銭 | 格上げは**民の負担（県の銭は減らない）**。工事中（数日）は収容数がその前のレベルのまま |
| 需要メーターで新築の可否 | 廃止。代わりに「空き家」「入居待ち」「働き口」「失業」を表示 |
| 人口は住居の収容数へ向かう | いまのまま（空き家があり、民忠・食糧が良いほど早く入居） |
| 仕事は都市全体で農→工→市の順 | いまのまま。ただし**道路網につながっていない建物には人が住まず、働かない** |
| 畑は1マスごと | 畑1枚（4×4=16マス）の収量 = 1マスの収量 × 16。働き口も同じ。肥沃度は16マスの平均。数値は balance で調整 |
| 工房の種類は自動 | プレイヤーが選ぶ |

- 満足度が低い状態が続くと、いまと同じく レベルが下がる → レベル1で空き家 → 長く空き家なら廃屋（撤去はせず、色が褪せて「修繕」できる。修繕は建設費の半分）。プレイヤーが置いた物が勝手に消えないようにするため。
- 道路が届かない・水がないなどで満足度が低い建物は、情報パネルに「満足度の内訳」と「助言」を出す（いまの `explainBuildBlockers` を作り直す）。

## 5. 建設材料（木材・石材）

- 上部バーに 銭・穀・**木材**・**石材**・人口 を並べる（添付画像の並びに合わせる）。
- 手に入れ方:
  - **伐木場**（2×2、森の近く）: 周りの森のマス数に応じて毎月木材ができる。森を伐採（畑・建物を置く）しても少し手に入る。
  - **石切場**（2×2、丘・山すその近く）: 毎月石材ができる。
  - 市の店があれば、銭で買える（割高）。足りなくて詰まることを防ぐため。
  - 商隊の交易品の「木材」とつなぐ（売り買いできる）。
- 使い道: 家・工房などは主に木材。石材は礎石・台基のある大きな建物（城門・宮殿・宗廟・橋・穀倉）に少しだけ。版築の城壁は土なので石材を使わない（銭と日数）。
- 時代考証: 戦国時代の建物は木造と版築で、石は礎石・基壇が主。この扱いを `02_時代考証メモ.md` に書く。

## 6. 表示・助言・セーブなど

- 表示モード「区画」→「用途」（住居・農業・商業…の色分け、空き家・廃屋の印）。「繁栄度」→「満足度」。
- 案内役の助言（`advice.json`）: `zone_blocked`・`demand_*` などの区画向けの文を、「空き家が多い」「働き口が足りない」「入居待ちが多い → 家を建てましょう」などに置き換える。
- チュートリアル: 道路を引く → 家を置く → 畑を置く → 井戸 → 待つ → パネル。
- 案内役の表情: 通常・喜び・心配・警告の4種。助言の種類（よい知らせ／注意／危険）で切り替える。画像は `assets/ui/advisor_normal.png` などの4枚（背景透過の PNG）。添付の画像から切り出せるが、背景透過の画像を頂けると仕上がりがよい。
- 開始の村: 家6・畑（4×4）2枚・農家2・井戸を、新しい方式の建物として置く。
- セーブ: 版を 2 に上げる。版1（区画方式）は読み込み時に「古い形式（区画方式）のため読めません」と出す。保存枠の一覧でも「読めない」と表示し、削除はできる。

## 7. 移行の手順（各段階で遊べる状態を保つ）

| 段階 | 内容 | 終わったときに遊べること |
|---|---|---|
| 1 | 共通項目のデータ、1つずつ置く操作（見本・緑赤の枠・理由・回転・決定） | 区画方式と並んで、建物を手で置ける |
| 2 | 畑 4×4（並べ置き・範囲）、線引きの見直し、移動・撤去・元に戻す | 畑も手で置ける |
| 3 | 計算の切り替え（入居・就業・満足度・自動格上げ・廃屋と修繕）。区画の自動成長を止める | 置いた建物で街が育つ |
| 4 | 木材・石材（伐木場・石切場・市で購入・上部バー・費用） | 材料を集めて建てる |
| 5 | 区画方式の削除、建築バーのタブ、表示モード、助言・チュートリアル、開始の村、セーブ版2、表情4種、docs の更新 | 新方式だけで最後まで遊べる |

## 9. 既定値で進める細部（変えたいときは指示ください）

- 庶民の家は 1×1 のまま。工房は 2×2 に広げる。
- 移動の費用 25%、撤去で木材 50% 戻る。
- 格上げの条件: Lv2 = 水と市が届く、Lv3 = それに加えて宗廟か学宮が近い（士・貴族の邸）。庶民の家の Lv3 は宗廟の代わりに社稷壇でも可。
- 廃屋は自動で消さない（修繕か撤去をプレイヤーが選ぶ）。
- 鉄山（鉱山）の建物は今回は入れない（製鉄工房は近くの鉄の資源で動く、いまのまま）。必要なら段階4の後に追加。
