# 戦国七雄・都市開発シミュレーション（仮題）

中国・戦国時代後期（前247年〜）を舞台にした、ブラウザで動く3D都市開発シミュレーションゲームです。
七雄のいずれかに仕える県令として一都市を発展させ、郡守・相邦/大将軍へと出世し、天下統一を目指します。

## 状態
- フェーズ6（軍事: 徴兵・陣形・出陣・侵攻と守城）まで実装済み。人物は史実の41名（全員に出典と要確認の注記）。描画はコード生成モデル（家・畑・樹木・牛馬と車・関節つきの住民、手続きテクスチャ、LOD）。
- 上部の「表示」ボタン（Tab で順送り）で区画・水・治安・繁栄度などのデータマップを重ねて見られます。
- 右下のフクロウ「ホウ」が状況に応じて助言し、初回は基本操作を案内します（設定で頻度を変えられます）。
- 公開URL: https://onestop0716-dot.github.io/sengoku-city/
- 設計書: [`docs/`](./docs/)

## 動かし方
```
cd sengoku-city
npm test         # ロジックテスト
npm run serve    # http://localhost:8080/ で起動
node tools/screenshot.mjs out.png   # 実描画のスクリーンショット（Playwright が必要）
```
ビルド工程はありません。`sengoku-city/` フォルダをそのまま静的ホスティング（GitHub Pages 等）に置けば動きます。
